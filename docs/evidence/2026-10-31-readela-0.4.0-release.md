Mozilla's `addons-linter` 10.15.0 on the Firefox archive of the cloud clone:
0 errors, 0 notices, 0 warnings.

The release Gate required the three digests to agree, so it did not pass and
nothing was tagged or released. Cause: a zip entry stores local time, and
`git archive` writes the commit time in the machine's time zone. With `TZ=UTC`
set, the owner's computer gave `a6fdc40f…6271`; line endings play no part.
The files in the two archives are the same.

Fix: `scripts/source-package.mjs` runs `git archive` in UTC, and the README
says why. In the cloud the archive of the fix commit gave the same digest with
`TZ=Australia/Sydney` and with `TZ=UTC`. The release is made from the commit
that carries the fix.
